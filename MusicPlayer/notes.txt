This project is a local music player built with Python, PySide6, and a web-based interface using HTML, CSS, and JavaScript.

Main features:
- Load and browse music from a selected folder or drive
- Scan common audio files such as MP3, WAV, FLAC, OGG, and others
- Show track information like title, artist, album, and duration
- Play, pause, stop, next, and previous track controls
- Move through the song with a seek slider
- Adjust volume
- Display the track list and highlight the currently playing song
- Show simple feedback messages for errors or status updates

In short, it is a desktop music player with a stylish interface that lets users play local music files from their computer.
